sign-outs that don't lose information between shifts, prior auths that don't take nine
days, claims that don't die quietly in a payer portal.

## What I'm Building

**[Replicate.Health](https://replicate.health)** — AI agents for the work doctors hate.
Credentialing, prior authorization, and billing, automated end-to-end with
human-in-the-loop approval on every external action.

**[SanosMD](https://sanosmd.com)** — AI-powered clinical workflow automation for skilled
nursing facilities and telehealth providers. AI-driven documentation, clinical sign-out,
and real-time patient monitoring.
